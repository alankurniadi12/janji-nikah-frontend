# UI/UX Implementation Brief

## Landing Page Janji Nikah

## 1. Tujuan Utama

Landing page harus membuat calon member memahami dalam beberapa detik bahwa:

* Janji Nikah adalah platform untuk memulai jasa undangan digital.
* Tidak perlu jago desain.
* Tidak perlu coding.
* Tidak ada biaya bulanan.
* Member dapat membuat undangan untuk calon pengantin.
* Harga jasa ditentukan sendiri oleh member.
* Kredit hanya digunakan saat publish.

Primary conversion:

**Mulai Gratis**

Secondary conversion:

**Lihat Contoh Undangan**

---

# 2. Prinsip Desain

## Mobile First

Landing page harus dirancang terlebih dahulu untuk layar smartphone.

Target pengalaman:

* nyaman dibuka dari link Instagram, TikTok, Facebook atau WhatsApp,
* tidak membutuhkan zoom,
* tombol mudah ditekan dengan satu tangan,
* teks tidak terlalu panjang,
* section mudah discan,
* visual tetap menarik meskipun layar sempit,
* loading image dijaga agar ringan.

Desktop merupakan versi yang memanfaatkan ruang lebih besar, bukan sumber layout utama yang kemudian dipaksa menjadi mobile.

---

# 3. Brand Direction

Karakter:

**Friendly, modern, profesional, mudah digunakan, dengan sentuhan wedding yang elegan.**

Hindari:

* terlalu corporate,
* terlalu feminin,
* terlalu banyak bunga,
* gaya “cepat kaya”,
* desain wedding organizer tradisional,
* terlalu banyak gradient dan glow,
* penggunaan card berlebihan.

Target visual:

**70% modern SaaS + 30% wedding.**

# 18. Typography

Gunakan maksimal dua font family.

Saran karakter:

Heading:

* elegant modern,
* sedikit personality,
* tetap readable.

Body:

* modern sans-serif.

Jangan menggunakan font script/calligraphy pada landing page utama.

Font dekoratif hanya boleh muncul pada mockup undangan.

---

# 19. Border Radius

Konsisten.

Suggested:

Buttons:
10–14 px

Cards:
16–20 px

Large visual containers:
20–28 px

Jangan setiap komponen menggunakan radius berbeda.

---

# 20. Shadows

Soft.

Jangan menggunakan shadow hitam pekat.

Gunakan shadow hanya untuk:

* mockup,
* floating visual,
* important cards.

Sebagian besar section cukup dengan border atau background contrast.

---

# 21. Mobile Spacing

Mobile side padding:

sekitar **20–24 px**

Section vertical spacing:

sekitar **72–96 px**

Jangan terlalu rapat.

Tetapi jangan pula membuat setiap section setinggi satu layar hanya karena banyak whitespace.

# 23. Performance

Karena traffic utama berpotensi dari sosial media dan mobile:

* gunakan WebP/AVIF jika memungkinkan,
* lazy-load gambar di bawah fold,
* jangan lazy-load hero visual,
* gunakan ukuran image sesuai viewport,
* jangan mengirim asset desktop 4K ke mobile,
* compress screenshot dan mockup,
* hindari video autoplay pada V1.

Target landing page harus tetap nyaman pada koneksi seluler biasa.

---

430 px

768 px

Desktop:

1280–1440 px

Layout tidak boleh hanya diuji pada desktop dan satu breakpoint mobile.

# 25. Accessibility

* contrast text harus jelas,
* CTA jangan hanya dibedakan berdasarkan warna,
* image memiliki alt text,
* focus state tombol/link tetap terlihat,
* ukuran body mobile sekitar 16 px,
* interactive target cukup besar.
