# Landing Page Copy

Dokumen ini menjadi pegangan copywriting landing page Janji Nikah.

## Positioning

Janji Nikah adalah platform untuk member/reseller yang ingin menjual jasa undangan pernikahan digital tanpa membuat sistem sendiri.

Fokus utama landing page:

- Menjual peluang jasa undangan digital.
- Menunjukkan hasil undangan yang terlihat profesional.
- Membuat calon member paham bahwa modalnya terukur.
- Mengarahkan user untuk login Google atau melihat demo tema.

## Target Audience

- Reseller undangan digital.
- Freelancer desain atau admin wedding.
- Wedding organizer kecil.
- Penjual lokal di WhatsApp, Facebook, Instagram, atau komunitas sekitar.
- Orang yang punya akses ke calon pengantin dan ingin produk jasa tambahan.

## Core Message

Headline utama harus menekankan manfaat bisnis, bukan sekadar fitur aplikasi.

Contoh arah headline:

```text
Buka jasa undangan digital yang terlihat siap dijual sejak hari pertama.
```

Supporting copy:

```text
Janji Nikah membantu member membuat undangan pernikahan digital untuk klien: pilih tema, isi data, preview gratis, publish pakai kredit, lalu bagikan link personal ke tamu.
```

## CTA

Primary CTA:

```text
Masuk / Daftar dengan Google
```

Secondary CTA:

```text
Lihat Demo Tema
```

## Key Selling Points

- Preview tidak memotong kredit.
- Publish memakai 1 kredit.
- Katalog tema bisa ditunjukkan ke calon pengantin.
- Link tamu personal.
- RSVP dan ucapan tamu.
- Copy teks WhatsApp.
- Dashboard member untuk mengelola draft, undangan aktif, dan transaksi.
- Branding/promosi member.

## Copy Tone

Gunakan Bahasa Indonesia yang:

- Praktis.
- Jelas.
- Percaya diri.
- Tidak terlalu puitis.
- Tidak terlalu teknis.
- Ramah untuk reseller pemula.

Hindari copy yang terdengar seperti:

- Template murah.
- Aplikasi desain rumit.
- Janji cepat kaya.
- Wedding marketplace untuk calon pengantin langsung.

## Recommended Sections

1. Hero
   - Brand/product name.
   - Headline peluang bisnis.
   - Supporting copy.
   - CTA login dan demo tema.
   - Hero visual.

2. Value Proof
   - Preview gratis.
   - 1 kredit per publish.
   - Link personal tamu.

3. Showcase Tema
   - Modern.
   - Elegant.
   - Floral.
   - CTA ke katalog tema.

4. Cara Kerja
   - Beli kredit.
   - Buat undangan.
   - Bagikan link.

5. Untuk Siapa
   - Reseller.
   - Freelancer wedding.
   - Penjual lokal.

6. Final CTA
   - Ajakan membuat akun.
   - Ajakan melihat demo tema.

## Honest Positioning Notes

Janji Nikah paling cocok untuk calon member yang sudah punya akses ke pasar. Landing page tidak boleh memberi kesan bahwa order akan datang otomatis hanya karena punya akun.

Copy yang disarankan:

```text
Cocok kalau kamu sudah punya jalan ke calon pengantin dan butuh produk digital yang rapi untuk ditawarkan.
```
